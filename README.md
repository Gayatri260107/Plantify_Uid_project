# 🌿 Plantify - Flutter Plant Shopping App

Plantify is a simple frontend plant shopping application developed using Flutter and Dart.

The project demonstrates Flutter UI design, navigation, form validation, animations, REST API integration, and basic unit testing.

## 📱 Features

- 🌿 Plantify home page
- 🌱 Plant categories
- 🪴 Popular plant products
- 🏷️ New product badges
- 🛒 Add to Cart / Order navigation
- 📝 Order form
- ✅ Form validation and error handling
- ✨ Fade animation
- 🌐 REST API product fetching
- 🧪 Basic unit testing
- 📱 Responsive and scrollable UI

## 🛠️ Technologies Used

- Flutter
- Dart
- Material Design
- REST API
- HTTP package
- Flutter Testing Framework
